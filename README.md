# 67餐厅

一个运行于 Minecraft 1.20.1 Forge 的怪诞餐厅主题模组。玩家可以用「小丑的门」主动生成 67餐厅，在餐厅中遭遇 67小丑、品尝一盘咖喱，并承担状态效果结束后被警狗追杀的风险。

> 当前项目仍处于开发阶段。玩法、数值和资源可能继续调整。

## 主要内容

### 小丑的门

- 在方块顶面使用后，以保存的结构模板生成「67餐厅」。
- 结构生成成功时会同时生成一只 67小丑。
- 配方为一个任意原版门放在中心，周围八格放置任意带有 `c:foods` 标签的食物。
- 有 5% 的概率通过模组的全局战利品修改器加入村庄箱子战利品；该概率可以在数据文件中调整。
- 结构空间不足或结构文件缺失时不会消耗物品。

### 67小丑

- 拥有 40 点生命值，以游荡和观察玩家为主，不会主动攻击生物。
- 每次技能以自身为中心检查 50 格范围内的玩家，并施加持续 5 分钟的「67餐厅」效果。
- 技能成功命中玩家后进入 10 分钟冷却；首次生成后会尽快进行第一次检查。
- 生命值首次降至一半时，会无视冷却立即刷新一次技能。
- 拥有「67餐厅」效果的玩家无法伤害 67小丑；没有该效果的玩家可以正常造成伤害。
- 死亡时掉落一个「小丑的门」。
- 和警狗一样，会在和平难度下消失。

### 67餐厅状态效果

- 效果自然结束时，会立即在对应玩家附近召唤四只警狗。
- 玩家饮用牛奶清除效果，或在使用不死图腾的过程中移除效果，也会立即结算并召唤警狗。
- 警狗优先生成在下方为完整方块的可活动空气方块，其次尝试非完整支撑方块；没有合适位置时会在玩家附近重叠生成，以确保能够追击目标。

### 警狗

- 拥有 20 点生命值、10 点护甲、16 点攻击伤害和 `0.4` 移动速度。
- 不可驯服、不可牵引，也不会对食物产生反应。
- 召唤后锁定使对应「67餐厅」效果结束的玩家，不会因为受到其他玩家攻击而自然转移仇恨。
- 不会主动攻击骷髅。
- 被追击的玩家死亡后，同组四只警狗会立即消失且不产生掉落物。
- 会在和平难度下消失。

### 一盘咖喱

- 是可放置在其他方块上方的不完整方块，共可食用四次。
- 每次食用恢复 1 点饥饿值和 1 点饱和度。
- 第一次食用：获得 10 秒反胃。
- 已有反胃时食用：刷新反胃并获得或刷新 10 秒中毒。
- 已有反胃和中毒时食用：刷新两者并获得或刷新 10 秒失明。
- 同时拥有反胃、中毒和失明时再次食用：受到特殊致死伤害。
- 第四次食用后，咖喱方块消失，并清除玩家身上的「67餐厅」效果。
- 未食用过的咖喱被破坏时会掉落物品；食用过任意次数后再被破坏则不会掉落。

## 获取内容

所有当前可获取物品均收录在创造模式的「67餐厅」标签页中：

- 小丑的门
- 一盘咖喱
- 67小丑刷怪蛋
- 警狗刷怪蛋

## 开发环境

首次构建前请确认已安装 Java 17，并让 Gradle 使用该版本：

```powershell
.\gradlew.bat build
```

常用开发运行配置：

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
```
